## 이 프로그램이 지키는 것

- 부서 기준금액을 고쳐도 **이미 등록된 학생의 금액은 저절로 바뀌지 않습니다.**
  반영은 사람이 [부서금액 반영]을 눌렀을 때만 일어나고, 그때도 무엇이 어떻게 바뀌는지
  먼저 보여 줍니다. 학생별로 고쳐 둔 금액은 기본 방식에서 그대로 지켜집니다.
- **수강 취소는 자료를 지우지 않습니다.** 상태만 취소로 바꾸고 사유를 받습니다.
  되돌릴 수 있고, 변경 이력에 남습니다.
- 작업공간 순서는 **시작일 하나**로 정해집니다. 화면에 보이는 차례가 곧 지원금
  누적 계산의 차례입니다.

## 개발

```bash
npm install
npm run app        # 개발 중 실행 (창이 뜹니다)
npm run check      # 타입 검사 + Rust 단위 테스트
npm run app:build  # 설치 파일 만들기
```

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 화면만 브라우저에서 (Tauri 명령은 동작하지 않습니다) |
| `npm run build` | 타입 검사 + 화면 번들 |
| `npm run check` | `tsc --noEmit` + `cargo test` |
| `npm run version:set 0.2.0` | 버전 세 곳을 한꺼번에 맞춤 |

## 구조

```
src/                      화면 (React + TypeScript)
  components/             공용 UI — 표 · 팝업 · 토스트 · Excel 도구 · 수강 팝업
  pages/                  화면별 구현
  ipc/                    Rust 명령 호출 (api.ts) 와 타입 (types.ts)
  lib/                    포맷터 · 전역 상태
  styles/                 디자인 토큰과 공용 스타일
src-tauri/
  migrations/00N_*.sql    스키마 원본 — 배포된 파일은 고치지 않는다
  src/db/                 연결 · 마이그레이션
  src/repo/               SQL
  src/domain/             업무 규칙 (DB 의존 없음, 테스트 대상)
  src/excel/              읽기(calamine) · 쓰기(rust_xlsxwriter)
  src/commands/           IPC 껍데기 (로직 없음)
```

## 자료가 저장되는 곳

| 대상 | 위치 |
|---|---|
| 업무 DB | `%APPDATA%\kr.school.afterschool\afterschool.db` |
| 백업 | 위 폴더의 `backups\` |
| Excel 출력 | 위 폴더의 `exports\` |
| 로그 | 위 폴더의 `logs\` (30일 보관, 개인정보 없음) |

실행 파일과 자료를 나누어 두었으므로 **프로그램을 업데이트해도 자료는 그대로**입니다.
자료구조가 바뀌는 업데이트에서는 적용 직전에 `backups\`로 자동 백업합니다
(파일 복사가 아니라 SQLite 백업 API를 씁니다).
