# 앱 아이콘

> **지금 들어 있는 파일은 임시 아이콘입니다.**
> 보결 배정 시스템의 아이콘을 그대로 복사해 둔 것이므로 배포 전에 교체해야 합니다.

## 준비할 원본 하나

| 항목 | 값 |
|---|---|
| 형식 | PNG |
| 크기 | **1024 × 1024** (정사각형) |
| 배경 | 투명(알파 채널) 권장 |
| 여백 | 아이콘 그림이 캔버스에 꽉 차지 않게 바깥쪽에 8~10% 여백 |
| 모서리 | **둥글게 깎지 마세요.** Windows가 알아서 처리합니다 |
| 색 | 작게 줄여도 알아볼 수 있게, 색 대비를 크게 |

작업표시줄에서는 16×16까지 줄어듭니다. 글자를 넣으려면 두 글자 이내로 하고,
가는 선은 피하세요.

## 교체 방법

원본을 아무 곳에 두고 프로젝트 루트에서 한 번만 실행합니다.

```bash
npx tauri icon 경로/아이콘.png
```

이 명령이 이 폴더의 파일을 **전부 새로 만듭니다.**

- `32x32.png`, `128x128.png`, `128x128@2x.png` — 창·목록용
- `icon.ico` — Windows 실행파일과 설치파일 아이콘
- `icon.icns`, `Square*Logo.png` 등 — 다른 플랫폼용 (Windows 배포에는 쓰이지 않음)

`tauri.conf.json`의 `bundle.icon`과 `bundle.windows.nsis.installerIcon`이 이미 위
파일들을 가리키고 있으므로 **설정은 고칠 필요가 없습니다.**

교체한 뒤 확인할 것:

```bash
npm run app:build
```

- 설치파일 아이콘
- 시작 메뉴 아이콘
- 실행 중 작업표시줄 아이콘

세 곳이 모두 새 아이콘이면 끝입니다. 아이콘만 바꿔도 Windows가 예전 아이콘을
캐시하고 있을 수 있으니, 바뀌지 않아 보이면 로그아웃 후 다시 확인하세요.
