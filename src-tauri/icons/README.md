# 앱 아이콘

지금 아이콘은 **2026-09-06에 교체한 정식 아이콘**입니다.
원본은 이 폴더의 `source.png` 하나이고, 나머지 파일은 모두 여기서 만들어집니다.

## 원본 (`source.png`)

| 항목 | 값 |
|---|---|
| 크기 | 1254 × 1254 (정사각형) |
| 형식 | PNG, **알파 채널 있음** |
| 그림 영역 | 1096 × 1102, 사방 여백 약 6% |
| 모양 | 모서리가 둥근 사각형(스퀘어클), 바깥은 투명 |

### 받은 그림에서 무엇을 고쳤나

받은 원본은 알파 채널이 없고(`Format24bppRgb`) 바깥쪽이 **불투명한 검정**이었습니다.
그대로 쓰면 작업표시줄과 시작 메뉴에서 검은 사각형 안에 아이콘이 든 모양이 됩니다.

그래서 **바깥쪽 검정만 투명으로 바꿨습니다.** 그림 자체는 손대지 않았습니다.
도형이 볼록하므로 각 가로줄을 좌우 바깥에서 안쪽으로 훑으며 거의 검정인
픽셀만 지웠고, 그림 안의 짙은 남색(지붕·문)은 건드리지 않았습니다.
경계 한두 픽셀은 밝기에 따라 알파를 매겨 계단이 지지 않게 했습니다.

## 다시 만드는 방법

원본을 바꿨다면 프로젝트 루트에서 한 번만 실행합니다.

```bash
npx tauri icon src-tauri/icons/source.png
```

이 명령은 다른 플랫폼용 파일(`android/`, `ios/`, `icon.icns`, `Square*Logo.png`
등)도 함께 만듭니다. **이 앱은 Windows 전용이므로 쓰이지 않는 것은 지웁니다.**
남겨야 하는 파일은 `tauri.conf.json`이 가리키는 넷뿐입니다.

| 파일 | 쓰임 |
|---|---|
| `32x32.png` · `128x128.png` · `128x128@2x.png` | 창·목록 |
| `icon.ico` | 실행파일 · 설치파일 · 시작 메뉴 (16·24·32·48·64·256 포함) |

`bundle.icon`과 `bundle.windows.nsis.installerIcon`이 이미 위 파일들을 가리키므로
**설정은 고칠 필요가 없습니다.**

## 새 원본을 만들 때 지킬 것

| 항목 | 값 |
|---|---|
| 형식 | PNG, **투명 배경 필수** |
| 크기 | 1024 × 1024 이상, 정사각형 |
| 여백 | 바깥쪽에 5~10% |
| 모서리 | 둥글게 깎아도 됩니다. **Windows는 아이콘을 그대로 보여 주며 스스로 둥글게 만들지 않습니다** |
| 색 | 16 × 16까지 줄어드니 대비를 크게, 글자는 두 글자 이내 |

배경을 투명으로 두는 것이 가장 중요합니다. 검정이나 흰색으로 채워 두면
밝은 작업표시줄이나 어두운 메뉴에서 네모난 판이 그대로 보입니다.

## 교체한 뒤 확인

```bash
npm run app:build
```

설치파일 아이콘 · 시작 메뉴 아이콘 · 실행 중 작업표시줄 아이콘,
세 곳이 모두 새 아이콘이면 끝입니다. 바뀌지 않아 보이면 Windows가 예전 아이콘을
캐시하고 있는 것이니 로그아웃 후 다시 확인하세요.
